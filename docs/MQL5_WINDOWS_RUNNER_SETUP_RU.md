# Настройка Windows runner для компиляции MQL5

Этот runner нужен для настоящей компиляции через MetaEditor. GitHub Actions на Linux не может заменить MetaEditor и тестер MT5.

## Важная безопасность

- Репозиторий публичный. Не запускайте self-hosted runner для событий `pull_request` от посторонних пользователей.
- Новый workflow намеренно запускается только по push в доверенную ветку `fix/smc-trend-follower-v1-1` и вручную.
- Не сохраняйте пароль торгового счёта, API-ключи или другие секреты в репозитории и логи.
- Для runner используйте отдельную учётную запись Windows без прав администратора и без доступа к личным файлам, если это возможно.

## Однократная настройка

1. На Windows-ПК установите MT5 от своего брокера и откройте MetaEditor, чтобы убедиться, что он работает.
2. Откройте репозиторий GitHub: **Settings → Actions → Runners → New self-hosted runner**.
3. Выберите **Windows** и **x64**. GitHub покажет команды скачивания runner и одноразовый токен регистрации. Выполните показанные команды в PowerShell в отдельной папке, например `C:\\actions-runner`. Не публикуйте токен и не вставляйте его в репозиторий.
4. Когда мастер предложит дополнительные labels, добавьте label `mql5`. Оставьте стандартные labels `self-hosted`, `windows`, `x64`.
5. Запустите runner командой, которую покажет GitHub, и убедитесь, что в Settings → Actions → Runners он отображается как **Idle/Online**.
6. Оставьте runner запущенным. Для постоянной работы можно настроить службу Windows по официальной инструкции GitHub, учитывая рекомендации безопасности выше.

## Запуск компиляции

1. Откройте вкладку **Actions** репозитория.
2. Выберите **MQL5 Windows compile**.
3. Нажмите **Run workflow** и выберите ветку `fix/smc-trend-follower-v1-1`.
4. Откройте результат запуска и скачайте artifact `mql5-compile-output`. В нём будет журнал MetaEditor и, если компиляция создала его, файл EX5.

## Что проверяется и что нет

- Workflow `MQL5 source checks` выполняет статические проверки Python. Его зелёный статус **не означает**, что советник скомпилирован или прибыльно протестирован.
- Workflow `MQL5 Windows compile` вызывает MetaEditor на вашем Windows runner и проверяет журнал компиляции.
- Стратегический тест MT5 пока не автоматизирован: для него требуется настроить терминал, символ, период, диапазон дат, модель тиков, депозит, плечо и файл конфигурации тестера. Нельзя выдавать статическую проверку или одну компиляцию за бэктест.

Официальная инструкция GitHub: https://docs.github.com/en/actions/hosting-your-own-runners/managing-self-hosted-runners/adding-self-hosted-runners
