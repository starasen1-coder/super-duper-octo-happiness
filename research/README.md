# Research

Исследования должны быть воспроизводимыми. Исходные данные не изменяются; очистка создаёт отдельный набор.

Минимальные признаки:
- H1 BOS/CHoCH;
- M5 liquidity pool;
- sweep + close-back;
- impulse ATR-relative;
- candle body/range;
- displacement;
- Volume Profile POC/VAH/VAL;
- session;
- spread;
- distance to liquidity;
- risk/reward to next liquidity.

Каждый сигнал получает timestamp и outcome после фиксированного горизонта или TP/SL.
