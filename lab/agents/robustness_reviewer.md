# ROBUSTNESS REVIEWER

Проверить переоптимизацию.

Минимум:
- IS/OOS;
- соседние параметры;
- разные даты;
- повышенный спред/комиссия;
- Monte Carlo порядка сделок;
- небольшая задержка входа;
- небольшие изменения SL/TP.

PASS только если преимущество не исчезает при небольших изменениях условий. FAIL, если результат существует только в узком наборе параметров.
